A program that writes one original line — the funniest single-line resignation letter — to `/output/entry.txt`.

Entry: "I hereby resign: the printer has seen things, the coffee machine has filed for divorce, and after today, so have I."

Run with `python3 main.py`. See [The One-Line Exit on make.fun](https://make.fun/c/u-kreutzx-the-one-line-exit-1dc652d1).
